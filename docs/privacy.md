# Easy Rental Search — Privacy Policy

_Last updated: November 7, 2026_

Easy Rental Search is an open-source Chrome extension. It has no servers, no accounts, no analytics and no tracking.

**What it reads.** When you open the side panel on a rental listing (Airbnb, Vrbo, Booking.com and a few others), the extension reads that page's public listing details: title, description, photos, approximate location, host name, and the dates/price shown. It does this only on the tab you're looking at, only while the panel is open.

**Where data goes.**
- **Free tools** (reverse image search, smart searches, map): nothing is sent anywhere until you click a link. Clicking opens Google, Bing, Yandex or TinEye in a new tab with that photo URL or search phrase, under those services' own privacy policies.
- **AI Deep Search** (optional): if you add your own Anthropic API key and press "Find its own website", the listing details and photo URLs are sent directly from your browser to the Anthropic API (api.anthropic.com), which runs web searches to find the property. See [Anthropic's privacy policy](https://www.anthropic.com/legal/privacy).

**What's stored.** Your API key and model choice are saved in Chrome's local extension storage on your device. Search results are kept in session storage and cleared when you close the browser. Nothing is sold or shared with anyone.

**Contact.** Open an issue at https://github.com/griffincockfoster56/easy-rental-search/issues.
